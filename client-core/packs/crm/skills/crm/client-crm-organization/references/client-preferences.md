# Client-Specific Preference Storage Rule

When the user expresses a style, tone, workflow, or operational preference that applies to a particular client (examples: email tone to Leeya, where to store meeting notes, communication cadence), record the rule in that client's `AGENTS.md` file rather than (or in addition to) global memory.

This ensures client-specific knowledge travels with the client context and is loaded automatically when working on that client.

Location: Add under a dedicated section such as `## Communication Style` or `## Agent Instructions` in the client's AGENTS.md.
