# Memory

Memory stores durable operating knowledge for the brain.

## Deep Memory

Use `memory/deep/` for conventions that apply broadly across the brain, such as communication preferences, artifact standards, and recurring operating lessons.

## Ephemeral Memory

Store narrow memory beside the file tree it supports:

- A client memory belongs in that client folder.
- A project memory belongs in the project folder.
- A skill memory belongs inside the skill folder.
- An artifact memory belongs beside the artifact.

## Semantic Recall

`mempalace.yaml` defines the starter recall rooms. Local deployments can run MemPalace or another semantic layer, but generated indexes and embeddings must stay local and ignored.
