# INDEX.md — Account / client information map

Structural only in the seed. No real account names.

## Folder structure

```text
Clients/
├── AGENTS.md
├── INDEX.md
├── schema.sql
├── Active/
├── Discovery/
├── Prospect/
└── Graveyard/
```

Each account folder:

```text
Clients/<Bucket>/<AccountName>/
├── AGENTS.md
├── RECALL.md
├── notes/
├── Materials/
└── Projects/
```

## Information map

- Profile and next steps: account `AGENTS.md`
- Structured CRM: local `Clients/clients_crm.db`
- Notes: `notes/YYYY-MM-DD-kebab-title.md`
- Materials: `Materials/`
- Projects: `Projects/`
- Semantic recall playbook: `RECALL.md`

Update this index when bucket types or locations change after Discover.
